# Changelog

Full changelog

## Release 2.1 (November 2025)

- Added missing weapon HUD section inheritance from `hud_base` (@Drombeys)
- Added support for Clear Sky (@St4lker0k765)

## Release 2.0 (June 2025)

- Fixed **PM** and **PB** pistols texture overlighting when used with flashlight (@MSR)
- Added **diopter sight** on **LR-300**, updated silencer (@MSR)
- Reduced fly width on **AK-74u** for easier aiming @MSR)
- Fixed **PB** silencer model - now antialiasing is correct, polygons are no longer visible (@MSR)
- Fixed weights and bone binding of hand models (@MSR)
- Returned **DTK** model on **SVU** rifle (@MSR)
- Fixed **SIG P220** reamer (front sight and front sight) (@MSR)
- Fixed **hud** hand animations** for all weapons (no longer twists wrists):
  **PM, PB, Desert Eagle, SIG P220, Walther P99, HPSA, Colt 1911, Fort-12, USP.** (@MSR)
- Fixed **AS “Shaft ”** animation - HUD no longer rolls to the right when aiming (@MSR)
- Fixed animation of **SPAS-12** - HG no longer jerks the bolt (shotgun semi-automatic) (@MSR)
- Fixed **MP5** animation - there is now a smooth transition between `idle` and `aim` (previously the weapon jerked towards the left shoulder when firing in the scope) (@MSR)
- Fixed `aim_hud` positions for all weapons (@MSR, @Drombeys)
- Assigned new aiming positions for weapons with **barrel grenade launchers** (@MSR)

## Release 1.0 (April 2025)

- Fixed SEVA hands for Clear Sky (@St4lker0k765)
- Fixed SPAS12 animations
- Fixed incorrect bump for SEVA outfit hud hand
- Fixed incorrect bump for SVDm-2 weapon
- Added addon resources
